# AGENTS.md

Правила для AI-агента, работающего в этом репозитории.

## 1. Git

**Разрешено всегда (только чтение):**
- `git log`, `git status`, `git diff`, `git show`, `git blame` и любые
  другие команды, которые только читают историю и состояние репозитория.

**Только с явного разрешения оператора (всё, что меняет состояние git):**
- `commit`, `push`, `merge`, `rebase`, `reset`, `checkout`, `tag`,
  `cherry-pick`, `stash` (в т.ч. `pop`/`apply`/`drop`), создание/удаление
  веток, `fetch`/`pull` (когда они записывают данные в репозиторий) и любые
  прочие операции, изменяющие состояние git.

## 2. Комментарии в коде

- Не удалять комментарии без явной причины. Если комментарий устарел или
  стал некорректным — отредактируй его, но не удаляй молча.
- Комментарии пишутся только там, где они действительно полезны, и на русском языке.

## 3. Взаимодействие с оператором

- Можно и нужно спорить с оператором, если ты не согласен с его решениями.
  Приводи аргументы и предлагай альтернативы.
- После того как оператор принял окончательное решение — следуй ему.
